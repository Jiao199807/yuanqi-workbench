🧩 模块管理
勾选要在侧边栏显示的模块；也可以新增你自己的模块（如：健身减肥 / 理财规划）。
☁️ 多设备同步
设置一个「同步码」，在手机和电脑上填同一个码，数据就会自动同步。请记牢，换设备时要用来认领数据。
🔧 想要「真正自动」的多设备同步？
当前手机链接是纯静态托管，无法自动联网同步。两种办法：
① 同 WiFi 自动同步：在你的电脑上运行本项目的 server.js（需装 Node），手机和电脑连同一 WiFi，手机打开 http://电脑局域网IP:3000 即可自动同步；
② 任意地点自动同步：把 server.js 部署到任意支持 Node 的云服务器，或在「设置」里改用免费云存储（需自备 API Key）。
不确定怎么弄可以告诉我，我帮你配。
🗑️ 重置
仅清空本设备。同步码与云端数据不受影响（如已开启同步）。
